--- Pièges mesurés et corrigés (consignés au commit) ---------------------

1. CONSTRUCTEUR PAR DÉFAUT : ecj ajoute un constructeur synthétique à
   type.methods, positionné sur le NOM du type (sonde mesurée : Carre
   declStart=71, bodyStart=108, ctor=84) — l'ancre des membres filtre
   désormais declarationSourceStart >= bodyStart (les inserts
   tombaient AVANT la déclaration du type : « record expected »).
2. BLOC MONO-INSTRUCTION : les branches d'un if/else entre accolades
   sont des Block — le ternaire déballe avant d'éprouver.
3. types publics : une fixture multi-types publics (Main.java portant
   un second type public) est une ERREUR ecj qui TAIT la passe lint
   (garde commune) — les bancs V-C2 n'ont qu'UN type public par
   fichier.
4. ElementValuePair : la clé se lit par getName()/champ `name`
   (PAS « getKey() »), les valeurs par getValue().
5. Allocation de tableau : new int[] {…} enveloppe l'initialisateur
   (ArrayAllocationExpression.initializer) — @Size déballe avant de
   compter.
6. SuperfluousSemicolon NON ÉMIS par défaut (mesuré) — le mapping mort
   est écarté ; le cast redondant vivant est le signal de NOTRE
   inspection V-C1 (code nommé « RedundantCast »), d'où l'alias
   nommé dans fromCode.
7. try-with-resources : l'exemption se joue AU VERDICT (la visite du
   try précède celle des ressources — piste pas encore ouverte).
